About Me

[ NERV ] // PERSONNEL_FILE // CLASSIFIED ▶ ACTIVE

I'm a Computer Engineering student at Simon Fraser University with a focus on low-level firmware and embedded systems. I've interned at Astera Labs, where I wrote C firmware and SDK APIs for PCIe retimers and CXL memory controllers; at AiModels, developing ESP32 firmware for AI-powered IoT dataloggers; and at Ausenco, building Python tooling and dashboards for pipeline simulation software. I care about writing software that is correct, fast, and built to last.
